# Scan layout with existing widgets

The Profile needs a professional, emoji-free, easy-to-scan layout while keeping the typing SVG, summary Cards, streak, and isometric contribution graph. Section order is hero, contact, About as a single three-paragraph block, then proof widgets. Cards stay. The old nine-row linear stack is no longer the page spine, and the 3D graph stays.

**Considered Options**: two-column about; control-room framing; current linear restyle; scan layout that drops the 3D graph.

**Consequences**: About is one section, not a table. Trophies are out of the Card set. Theme on every remaining Card is Catppuccin Mocha. Hero copy is a greeting, so name-versus-typing overlap is a follow-up, not a reason to change this layout.
